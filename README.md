# Capital Conversion, Debt and Interconnectivity: A Formal Approach to Inequality among Nomadic Herders in the Xiongnu Empire
The repository contains the supplementary materials for the paper "*Capital Conversion, Debt and Interconnectivity: A formal Approach to Inequality among Nomadic Herders in the Xiongnu Empire*".

### Data
- **Simulation Raw Output** → Raw data produced by NetLogo simulations (see Appendix 2: NetLogo Code);
- **Appendix 1: Algorithm Description** → General description of the algorithm used in the different scenarios simulated;
- **Appendix 2: NetLogo Code** → NetLogo projects of the different scenarios simulated;
- **Appendix 3: Sensitivity Analysis** → Sensitivity analysis for the different scenarios simulated;
- **Appendix 4: R Scripts** → R scripts used to analyze the raw output of the simulations and to plot the figures used in the paper.
